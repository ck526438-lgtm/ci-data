ci-data

Open data & API pour la Côte d’Ivoire · Every Ivorian form needs a clean region → commune list

Ce que contient le dépôt

Chaque enregistrement porte sa source et un niveau de confiance (official / derived). Tout est régénéré par npm run build puis vérifié par npm test dans GitHub Actions.

Cascade district → commune

Les niveaux s’ajoutent tout seuls : un district sans sous-préfectures connue s’arrête à la commune.

        Utiliser les données

        # JSON brut, sans serveur (GitHub Pages)
curl https://ck526438-lgtm.github.io/ci-data/data/regions.json

# API locale
npm install && npm start
curl "http://localhost:3000/v1/regions?level=district"
curl "http://localhost:3000/v1/subdivisions?parent=CI-LG-03&level=commune"
curl "http://localhost:3000/v1/holidays?year=2026"
curl "http://localhost:3000/v1/phone-prefixes/resolve?number=0500112233"

# Paquet Node
const ci = require("./packages/js");
ci.getCommunes("CI-AB").map(c => c.name);   // les 17 communes du district d’Abidjan
ci.getPath("CI-AB-01").map(n => n.name);    // District Autonome d’Abidjan › Abidjan
ci.isHoliday("2026-08-07").name_fr;         // Fête de l’Indépendance
